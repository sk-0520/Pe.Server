# AI エージェント用ドキュメント

* 本ファイルは AI エージェントが参照すべきドキュメントである
* docs ディレクトリは開発者・AIエージェントが相互に編集可能であるが AGENT.md は AI エージェント専用のルートである
* なお、メモリとしては MEMORY.md にて管理せよ

## 読む順序

1. [全体指示](../.github/copilot-instructions.md) を守る。
2. [MEMORY.md](./MEMORY.md) で作業状況・保留事項を確認する。記録時点の情報なので、変更前に現在のコードを確認する。
3. 作業に対応する以下のスキルと、その参照資料を読む。

| 作業 | 参照先 |
|---|---|
| PHP の実装・調査・テスト | [PHP スキル](../.github/skills/php/SKILL.md)、[Core の指針](../PeServer/Core/README.md) |
| テンプレート・View の実装や移植 | [テンプレートスキル](../.github/skills/template-view/SKILL.md)、[移植の設計判断・検証方針](./TEMPLATE-MIGRATION.md) |
| Windows ローカルでの PHP 実行 | [ローカル PHP スキル](../.github/skills/windows-local-php/SKILL.md) |

このファイル名は `AGENT.md`（単数形）であり、自動検出用の `AGENTS.md` ではない。全体指示から明示的に参照する構成を維持する。

## 知識の管理

* 全作業に適用する短い指示は全体指示、分野別の作業手順はスキル、設計判断とその理由は分野別文書、作業状況・保留事項は MEMORY.md に記録する。同じ内容を各所へ複製せずリンクする。
* 決定事項と提案・未確認事項を区別する。エージェントの推奨を利用者の決定として記録しない。
* 設計判断には理由と適用範囲、作業状況には記録日・対象・確認方法を付ける。ソースに根拠がある場合は参照先を示す。
* 作業で決定・解決した内容は該当文書へ反映し、古い保留事項は更新する。会話全文や実行ログの蓄積はしない。
* 認証情報・秘密情報・個人情報は記録しない。開発用の値も転記せず、必要な場合にソースと環境条件を確認する。
* エージェント製品のメモリや会話履歴だけに依存せず、プロジェクトの知識はこの入口から辿れる Git 管理下の文書を正とする。
